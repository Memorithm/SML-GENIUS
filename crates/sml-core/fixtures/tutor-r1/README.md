# R1 bounded Rust program synthesis

Native symbolic induction over a closed grammar of nine typed `u8 -> u8` binary expressions. Each task has eight labeled TRAIN pairs, eight disjoint DEV pairs, and the remaining inputs split by parity of the encoded pair into TEST and TESTTEST. The learner receives only labeled examples and accepts exactly one matching expression. Ambiguity/inconsistency causes abstention. The mathematical oracle uses wider modular arithmetic and per-bit predicates; no expected output is supplied at inference. Canonical reload, generated source compilation via rustc, and exhaustive execution on all 65,536 operand pairs per task are mandatory. The only possible emitted expressions are reviewed, fixed, memory-safe, bounded and dependency-free. No arbitrary teacher-supplied code is executed. This is a controlled R1 programming acquisition, not general code generation or a compiler sandbox.
