# Exact global lexical routing index

Native Rust, 256 deterministic hash buckets per frozen language/source identity. Full hex lemma and optional POS equality, never hash-only matching. Each sense retains ordinal and shard locator, including the English delta. Build only in a new staging directory, verify exact projection of all source bank rows in a separate pass, reject cross-shard duplicate identities, then publish by a trusted RemoteOps controller after independently validating source manifests and hashes. Lookup scans one bounded bucket; it returns all matching sense addresses, not inferred meanings. No case folding, translation, or sense selection. This is a prerequisite for integrating lexical memory with dialogue, not a demonstration of conversational understanding.
