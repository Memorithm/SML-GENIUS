# C2 precursor: contextual sense selection

Original controlled synthetic labels, 4 ambiguous lexemes (2 per language), 8 local senses, 16 TRAIN examples and 48 disjoint TEST sentences (16 resolved and 8 unknown per language). Cues are induced from annotated context, then the intersection of known cue supports must contain exactly one sense. Contradictions or no evidence abstain. Shared cues are not treated as exclusive, unseen cues are ignored. IDs are local to this fixture, not real dictionary IDs. No claim of natural language understanding or independently authored evaluation; next stage binds stable source-scoped sense IDs after source link resolution. CLI teaches from labelled examples, restores canonical memory and evaluates each language and cohort independently. No teacher at inference.
