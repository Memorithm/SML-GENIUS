Controlled C1 benchmark: 5 supervised question/control templates per language, 16 independent sessions of 10 turns per language; test uses two L1 held-out verbs, unseen subject/object combinations. Facts arrive during conversation and are not baked into the model. Reuse actual L1 role parser, keep per-session memory isolated, resolve one recent-agent reference, distinguish unknown, explicit negation and contradiction, allow explicit revision of existing facts only. Response surface is deterministic French/English rendering, not learned free text generation. This does not certify open conversation or independent natural-language test. No teacher during inference. CLI modes --dialogue-learn L1 LESSONS QUESTIONS; --dialogue-verify L1 QUESTIONS fr|en TEST; --dialogue-run L1 QUESTIONS fr|en reads bounded newline-delimited stdin.
