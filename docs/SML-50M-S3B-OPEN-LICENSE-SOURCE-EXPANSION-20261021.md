## Priority 1 — Wikidata Lexeme CC0 (structured multilingual text)

License evidence: [Wikidata:Database download](https://www.wikidata.org/wiki/Wikidata:Database_download) and [Copyright](https://www.wikidata.org/wiki/Wikidata:Copyright): structured Lexeme namespace CC0, other wiki namespaces not necessarily CC0.

Pin this immutable dated object, NEVER the mutable `latest-` URL:
- Source URL: `https://dumps.wikimedia.org/wikidatawiki/entities/20261021/wikidata-20261021-lexemes.json.bz2`.
- Published compressed size: **483,529,071** bytes.
- Publisher SHA-1 checksum from `https://dumps.wikimedia.org/wikidatawiki/entities/20261021/wikidata-20261021-sha1sums.txt`: `7f8aa5b43334ad9f228ba3fce096d648f1f23959`. The upstream provides SHA-1, **not SHA-256**; on Dell compute SHA-256 over full downloaded bytes and persist its SHA-256 as a newly observed, host-local receipt before admission. SHA-1 alone is not strong content authentication; HTTPS, immutable dated URL, gzip/bzip integrity, complete byte-length, and computed SHA-256 add safeguards.
- First RemoteOps slice: download archive with TLS, 550-MB maximum, reject changed size/SHA-1/failed `bzip2 -t`, record measured SHA-256; source stays host-local and **no compressed bytes/public weight artifacts uploaded**. Source proof must say `SOURCE_VERIFIED_NOT_TRAINED`.
- Second slice: bounded native Rust streaming JSON extractor of Lexeme records only (`id`, `language`, `lemmas`, `forms`, `senses`), skip malformed/non-L lexemes and sensitive or over-limit records, preserve source entity IDs and language tags, SHA256 each extracted sample, dedup document text and work-family/lemma ID, cap each TRAIN/DEV document 128..2MiB, label `CC0_REVIEWED` only when namespace and source pinned and license evidence reviewed. Keep TEST frozen and independent. Split by **entity ID/family**, not document bytes; S1b DEV source hashes also excluded.
- Lexemes are a **structured lexical training/evaluation domain**. They cannot independently validate next-token general prose ability or a conversational assistant. Model next-task protocol should include lexical generalization and independent negative/positive controls.

## Priority 2 — PubMed Central Open Access (large actual prose; license per article)

Publisher: [PMC Article Datasets](https://pmc.ncbi.nlm.nih.gov/tools/textmining/) and [current AWS Cloud README](https://pmc-oa-opendata.s3.amazonaws.com/README.txt). Since **2026-08-26**, legacy FTP distribution was retired; current source is `s3://pmc-oa-opendata` / `https://pmc-oa-opendata.s3.amazonaws.com/`, anonymous HTTPS/S3 allowed. The current service covers roughly 8 million **article versions** across multiple different license classes; this is not 8M admitted examples. The publisher's JSON metadata in `metadata/PMC<ID>.<VERSION>.json` exposes `license_code`, `is_pmc_openaccess`, `is_retracted`, `doi`, `pmcid`, `title`, `citation`, `text_url`, and MD5 object digest. MUST select only explicit **CC0/CC-BY** code and additionally validate article's license statement, text object content/hash/MD5, titles/DOI/version, creator/author family and attribution; reject TDM-only, NC/ND/SA, missing license and retractions. Do not batch-scrape PMC main HTML site; publisher allows systematic acquisition via PMC Cloud, OAI-PMH, E-Utilities or BioC.
- First pilot: 1000 SHA/content-verified distinct current article-version `.txt` files sampled independently of prior S1b, capped by network/bytes, without model fitting; document sizes >=128 <=2,097,152 bytes, UTF-8, no HTML script execution, DOI/PMCID keyed dedup, very near duplicate screening and source manifest. Need an actual observed pilot before scaling to >=512MiB verified unique prose. No group leakage among articles from same research team or shared DOI.

## Priority 3 — DILA / LEGI French legal text (open license, attribution)

Official publisher [LEGI dataset](https://www.data.gouv.fr/datasets/legi-codes-lois-et-reglements-consolides), [open data index](https://echanges.dila.gouv.fr/OPENDATA/LEGI/) and [Licence Ouverte v2](https://www.data.gouv.fr/datasets/licence-ouverte-2-0). Dataset represents consolidated legislative/legal material, including historical revisions. A full `Freemium_legi_global_20250713-140000.tar.gz` archive is indexed at roughly **1.1 GB compressed** (not text bytes, and not proof of current content), and daily change tarballs continue. Verify its exact source checksum after download, archive traversal controls, applicable terms and attribution `source: DILA/LEGI`. Avoid including redundant historical variants of the same article across TRAIN/DEV; partition at instrument-family/article-ID level and dedup exact and fuzzy overlaps. License is **Libre/Open Licence with attribution**, not public domain/CC0; SML's roster must not incorrectly tag it CC0.

## Priority 4 — OpenAlex scientific metadata (not full research papers)

Publisher [OpenAlex AWS registry](https://registry.opendata.aws/openalex/): regular snapshot metadata CC0, public anonymous S3. 2026 public download [guide](https://help.openalex.org/tutorials/download-the-snapshot/) shows JSONL+Parquet ~1.5 TB total, each full format ~750 GB. Select **bounded** `data/jsonl/` works/keywords/concepts/author/entity subsets, NOT entire bucket, and count actual decoded metadata bytes. [OpenAlex's fulltext policy](https://help.openalex.org/access/fulltext/) explicitly says hosted paper PDFs retain their original copyright; metadata's CC0 does not license third-party fulltext. Exclude its original Microsoft MAG-format ODC-BY snapshot unless separately accepted with attribution. This is high-value scientific factual and graph data, lower priority for prose LM.

## Exclusion/qualification rules for every source

1. A directory/list (Kaggle, Hugging Face, OpenML, AWS, Kaggle notebooks or Awesome datasets) **does not grant a data license**. Check source-level and row-level licenses; distinguish **gratis** from **CC0/public domain** and **CC-BY/LO2 with attribution**. Avoid unknown, NC, ND, SA and mixed-license ingestion unless an explicit scoped exception and legal review have been preregistered.
2. Preflight exact immutable source reference, source authority, TLS/origin, published hashes or separately computed first-harvest digest, size, compression safety, file boundaries, resource budget, and provenance. No credentials or raw texts in public logs, PRs or artifacts.
3. Before any real training: isolate entirely new **SHA-verified unique content**, work/author/topic-family partition TRAIN/DEV, near-duplicate and language controls, provenance/attribution record, independent operator rights review, bounded disk memory and native Rust parser tests. A validation score measured on a changed domain cannot be blindly compared to older HF-only DEV.
4. **Measured gates:** fresh 512 MiB TRAIN target, >=32 MiB DEV target, holdout TEST untouched; fail with measured shortfall rather than inflating from epochs, archive sizes, dataset page counts or duplicated source versions. Keep S1b/S2a model as immutable comparison; no 25B, conversational, model-quality or training-speed superiority claim.
5. Control plane is RemoteOps and follows its `AGENTS.md` and off-main ecosystem roadmap. Owner-only runner, same-repo HEAD exact admission, source data never executed, no public fork CI execution of self-hosted scripts; no new uncontrolled resident process.
