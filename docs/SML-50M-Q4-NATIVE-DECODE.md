# SML-50M Q4 — read-only native byte generation

This is a **model-programme functionality**, not a new model or runtime. It
reuses `sml_core::sparse_gradient_atlas::QuantizedSparseAtlas`, the same
versioned F32→Q4 weight export and byte-factorization semantics used by
the SML-50M training/evaluation experiments.

## API and exact meaning

`QuantizedSparseAtlas::predict_next_byte(a, b)` computes the maximum
probability of **one whole byte** from the two previous bytes, using the
frozen exported Q4 weights. Independent-bits factorization evaluates eight
Bernoulli heads. MSB-tree factorization evaluates 255 internal nodes, then
scores all 256 eight-bit paths and chooses the highest-probability complete
byte. A per-bit greedy choice is **not** a whole-byte MAP decoder in general.
Equal byte probabilities select the numerically lowest byte. No target labels,
hidden future context, tokenization, training, or softmax attention are used.

The result records the predicted byte, its log2 probability, head evaluations,
and newly loaded 512-byte Q4 pages. Model capacity is *addressable* pages;
there is no claim that all pages were learned or that any SBG/MOR router was
trained. The model still routes by a fixed hash of the previous two bytes.

## Executable (trusted local Q4 file)

```bash
cargo test --locked -p sml-core --test q4_byte_generate
cargo run --locked --release -p sml-core --bin sml-q4-byte-generate -- \
  /path/to/weights.q4 LOWERCASE_SHA256 msb 4869 16
```

Arguments: `WEIGHTS.q4 SHA256 independent|msb SEED_HEX_4 COUNT_1_128`.
The example seeds on bytes `48 69` (ASCII `Hi`). The tool prints **hex**
only; arbitrary generated bytes are not guaranteed valid UTF-8. Factorization
must match the checkpoint that exported the Q4 file; Q4 has no self-describing
header. A supplied full-file SHA-256 must match before decoding. This is
local integrity screening, not hostile-host attestation or an immutable-file
guarantee under concurrent file mutation. Do not point at mutable artifacts.

RAM payload is bounded by the 32-page Q4 LRU; each selected byte may require
up to 255 logical page lookups, which is **not** an established physical
performance improvement. The CLI only accepts a 512-byte-aligned regular Q4
file no larger than 64 MiB and outputs at most 128 bytes per call.

## Qualification and limits

Tests compare the public decoder with an independently scored 256-byte
distribution on both factorization modes, test deterministic ties/cache
accounting and reject a modified artifact at the SHA gate. The read-only
path cannot silently train on DEV/TEST. Additional Dell physical validation
through `Memorithm/RemoteOps` is required to substantiate output,
page traffic, throughput and quality on an actual trained SML-50M
checkpoint. Neither unit tests nor this CLI establish an integrated
SBG/MOR/recurrent 50M model or a 25B language model.

No new corpus rights or promotion decision is implied.
