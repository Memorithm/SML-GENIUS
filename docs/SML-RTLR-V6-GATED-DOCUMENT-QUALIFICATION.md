# RTLR-V6 cost-gated whole-document inference — preregistered synthetic CPU benchmark

The research objective is to establish that conditional recurrent computation is actually skipped where a simpler Boolean feature ring already provides the same quality. This is not SML25B training or a claim of better language-model quality.

Three disjoint supervised TRAIN stages precede DEV. DISCOVERY uses 131072 TRAIN positions to mine the target delay, with known ANF feature function but no target lag supplied. FIT uses the next 196608 TRAIN positions to learn independent recurrent V3, preset V4 and mined V5; it also fits the Boolean-only null prior. CALIBRATION uses another 196608 TRAIN positions in inference-only mode, scoring the same target labels from Boolean-only and the frozen recurrent candidate on the same observations. Two disjoint calibration partitions (first two documents and final document) feed the TRAIN-only gate. No DEV data or labels influence selection. DEV has 65536 independently generated target positions.

Admission requires each TRAIN partition to satisfy: Boolean BPC minus recurrent BPC is greater than 0.001 plus 0.0001 times any extra measured recurrent nanoseconds per position. A tie, incomplete evidence or negative value selects Boolean-only. The route is immutable for an entire DEV document; at the start the model state is reset. A genuine Boolean-only routed DEV loop calls no recurrent inference methods. V3, V4 and V5 shadow comparators are scored independently for scientific comparison, but their work is excluded from the gated path timing. No switching mid-document, which would leave recurrence history stale.

Experimental grid: three generated source panels by tasks unknown lag64, lag1023 and unrelated-label null by initialization seeds 11, 23, 37, giving 27 trials per CPU host. All four phases use correct causal 1024-byte halo. The nullable miner returns zero candidates for null and the recurrent fallback is independent trained V3. A non-recurrent bit-ring using the identical TRAIN-found lag is measured separately on DEV.

Each trial prints 30 tab-separated RTLR_V6_ROUTE_V1 fields: schema, panel, task, seed, discovery/fit/calibration/dev counts, discovered lag, route ID (0 Boolean, 1 recurrent), actual DEV recurrent call count, six DEV losses (routed, Boolean-only, V5 shadow, V3, V4 and TRAIN-fit prior), routed/Boolean-only/V5 shadow DEV throughput, discovery bytes, ring bytes, V5 active width and logical payload bytes, V5 candidate weight, model training and other shadow DEV throughput. Route 0 must have exactly zero recurrent calls and reproduce the Boolean-only DEV loss; route 1 must invoke recurrence and reproduce the independent recurrent shadow loss.

The expectation on existing exact ANF tasks is route 0: the Boolean-only decoder is already optimal at the supplied feature. A correct refusal is a *functional* result, not improved general-purpose prediction. The Boolean routed loop timer includes allocation/halo priming while separate Boolean-only benchmark timing excludes them; the calibration recurrent timer includes reset/prime whereas Boolean comparator priming is outside its timer. Their rates cannot be treated as perfectly matched production end-to-end measurements. Native benchmarks must record both Dell and Thor results and resource constraints.

Rust 1.89, strict source pinned, CI green, nonroot Dell and Thor native artifacts required before merge. No physical 50M MOR/ANF model, SML25B training, GPU, CUDA, or SEC data; G0 NOT_ADMITTED, frozen 2024 TEST UNOPENED.
