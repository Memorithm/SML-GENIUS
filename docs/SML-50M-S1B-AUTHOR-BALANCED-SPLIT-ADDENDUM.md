# SML-50M S1b — size-balanced author-disjoint correction before any TRAIN

Date 2026-10-20. **Prospective protocol change relative to the aborted S1a preflight, not a reclassification of success.** S1a native RemoteOps [run #39493563045](https://github.com/Memorithm/RemoteOps/actions/runs/39493563045) completed model/compiler tests but stopped in corpus admission with `TRAIN=42,841,190` bytes and `DEV=54,792,671` bytes (804/3,285 documents). **No S1a model training executed, no DEV outcome/loss observed.** S1a assigned whole author groups by SHA modulo five; a few imbalanced group sizes made the 64-MiB TRAIN floor fail. The raw source, SHA and per-work licence filter remain frozen.

## S1b split correction — sizes only, no labels/metrics
For the same original pinned HF500 and **same strict CC0 + attributed CC-BY-only** eligibility as S1a, compute each eligible document's length, identifier and normalized creator group from the previously existing producer-supplied *provenance* first, before reading/training actual content. Exclude all PD_CLAIM, authorless or over-2MiB docs exactly as before. The approved source candidate is unchanged; if rights/review fail, STOP. This is a **TRAIN/DEV assignment engineering correction only**; not new statistically independent data.

Accumulate integer eligible byte totals per creator. Sort creators by ascending total eligible bytes; break ties by the raw 32-byte SHA-256 of normalized creator, then creator bytes for total order. Assign the smallest creator groups in that frozen order to DEV while `DEV < ceil(total eligible bytes / 6)`, **only when adding a whole group would leave at least 64 MiB in TRAIN**; other groups go to TRAIN. This guarantees no author split; all eligible documents of one normalized creator receive the same role; file hashes and cross-role dedup checks unchanged. A zero-document / under-4-MiB DEV or under-64-MiB TRAIN remains fatal. The number of documents, groups, and role bytes are recorded in the host-local evidence. No reverse-engineering by TEST scores, no hyperparameter or learning-rate change, and no rewrite of original S1a preflight outcome.

## Training / evaluation invariants unchanged
The model remains 50,000,896 F32 addressable positions, bounded 32-page LRU, `MsbTree`, frozen LR .15, 4,096-prediction-byte grouped SGD, full TRAIN then immutable-weight DEV F32/Q4 scoring, host-private master/Q4/snapshot and SHA-verified completion. Run resource limits on Dell under the RemoteOps controller; no new corpus download. Exact SHAs and rights/attribution receipts preserved. The frozen reserve SEC 2024 TEST remains `UNOPENED`; G0 `NOT_ADMITTED`; no claim about model quality or universal speed.
