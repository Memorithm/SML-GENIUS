# Native R1 cumulative admission

The physically qualified closed-grammar R1 example is refactored into
sml-core::tutor_rust_r1, preserving its canonical bank format, independent
oracle, compiler execution, CLI and receipt strings. The library separates
induction from direct bank examination. It never accepts arbitrary Rust.

The tutor now exposes Engine::open_rust_r1 and reexamine_r1. R1 is one real
Rust lesson containing nine expressions, not nine independently certified
lessons. The existing mastery gate receives counts computed from compiled
outputs and restored evaluation, with case partition identity grouped by
input pair across all nine tasks. The source binds canonical labels and
caller-attested provenance. External source lineage remains a controller
responsibility; CI uses an explicitly oracle-generated fixture.

The integration test publishes four mathematical functions and one Rust
bank into one cumulative store, re-examines all five entries, checks exact
replay and rejects wrong TRAIN labels without changing HEAD. This does not
yet connect Rust to the permanent daemon, qualify external labels physically,
or implement R2 in the cumulative engine. No production changes.
