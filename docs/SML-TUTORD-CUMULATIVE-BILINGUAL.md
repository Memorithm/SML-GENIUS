# Cumulative bilingual supervisor bootstrap

The opt-in bounded simulation accepts the existing five frozen L1 arguments.
Cycle zero uses real FR and EN L1 readmission plus the normal math-only
curriculum. The two language banks are certified, atomically published with
the math functions, and counted as re-examinations (not novel knowledge).
Later cycles read both banks directly from the cumulative store and run
the pinned native predictor over 1792 held-out cases without teaching.
All jobs bind the exact L1 curriculum and binary identity into their job ID;
changing inputs or the executable requires a fresh root. Exact cycle replay
reconstructs certificates only where needed. Existing math-only job identities
and cardinalities are unchanged. The mode remains bounded and non-production.

CI executes the actual daemon across two invocations, independently verifies
manifest lineage, bank hashes, 8 new math acquisitions and 2 re-admitted L1
banks, and checks retention output. This is not new linguistic learning,
a general conversation model, Rust integration or production activation.
