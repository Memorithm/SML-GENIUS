# Native L1 bridge — first real discipline integration

The P1 engine formerly dispatched only ANF tasks. This change keeps the original ANF backend and adds a sealed, built-in L1 backend; no teacher-provided examiner can be installed. The two actual language lessons enter the same registry, scheduler, work-stealing executor, journal, certificate gate and transaction store. ANF API and keys are preserved.

The teacher is a frozen admitted annotation corpus, independently checked against the original 192-row L1 labeled fixture. The existing native L1 executable learns only the admitted 48 rows; its DEV check never reads the TEST/TESTTEST files. All 896 held-out cases are grouped by triple before splitting to prevent paraphrase leakage. The adapter evaluates actual native predictions separately, demands exact reloaded checkpoint equality with the source bank, and requires a retention cohort for that bank. The engine certifies each cohort separately and stores the native bytes. Sequential and two-worker runs must agree, reopening must be a no-op, and a corrupted annotation must fail.

This is controlled re-admission of two L1 skills, not new linguistic learning, an open-domain conversation, fresh CUDA teacher generation or a production service. The test corpus is partitioned from previously published controlled cases; prospective independently authored evaluation remains necessary. The physical RemoteOps controller must pin the native executable source and verify the actual parent manifests, replay all V9 capabilities, bound process runtime and isolate the experimental store. No arbitrary generated code is run. Native process execution is restricted to that trusted caller-built executable; the adapter is not a sandbox for untrusted binaries. Worker/wave bounds are two until resource measurement integration.

Further steps: native mixed-domain curriculum, measured resource admission, Rust compiler-backed learner in a separate sandbox, actual physical qualification and consolidation into a reviewed common memory lineage. No change to existing frozen L1/C1 source files or physical stores.
