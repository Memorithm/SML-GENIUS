## License classification by row and dataset

**WitFoo Precinct6**: first-party-produced SOC event/incident corpus with `apache-2.0` dataset-card tag; card v2.1.0 dated 2026-09-22, roughly 2.25 million weak-labeled security events and 51,371 *automatically generated* attack summaries, not independent analyst confirmations. The whole dataset is ~8.41GB and includes production-origin but sanitized signals, logs, graph nodes and incident records; PII, secret and corporate data verification remains required before publication or training. First pinned pilot must use *only* `graph/attack_reports.jsonl` (~92.5MB) at exact upstream revision `96311c2e29611d8ddbf1c0d59f531f6a362b8233`. Technical use: **CYBER_SOC_WEAK_LABEL_CANDIDATE**, not pretraining proof of independently labeled attacks. Apache license claim and source rights must be checked before changing to `APACHE_2_0_ATTRIBUTION_REVIEWED` operator label. Preserve notices and original repository commit, source ID, artifact hash. No direct unrestricted use of raw production events.

**saidutta69/CyberSec-Reasoning-Premium**: card claims Apache-2.0 dataset-level but attributes five retained upstream sources with different licenses and 3,067 unique trace examples: `dpevzner-cr` 1,588 (Apache-2.0), `kimi-cyber-reasoning` 997 (WTFPL), `financial-ctf-defense` 333 (CC-BY-4.0), vulnerability reasoning 107 (Apache-2.0), CTF 42 (MIT); the user-visible dataset viewer displays preexisting system-prompt hijack strings. It also shows 2,606 original TRAIN rows, 230 VALIDATION and 231 TEST; data viewer may expose different serialized-view row counts and must not be used as final uniqueness proof. **DO NOT import upstream VALIDATION or TEST as SML TRAIN**; do not count mirrored `agent_traces` and `openai_chat` as independent training examples; first pilot only `openai_chat/train.parquet` (~6.72MB) pinned at HF revision `3aef736d3fd0a00167ac17744483ec601bdb716e`. Audit per-row `source`, `session_id`, normalised JSON message SHA, low-quality synthetic CoT, license provenance, PII, system-role instruction patterns and rejected clones. Keep outputs as untrusted data: **no dataset-provided system/developer instructions may be elevated to agent policy**. All LLM-generated CoT traces need model-output legal/contract and independent quality checking.

**Manusagents Omni-Frontier v2**: dataset-level `mixed-per-source`, approx 14.6GB, ~19.1M row index plus Python bytecode, security-gym raw SQLite archives and 9 files flagged unsafe by HF. It is a **copy of another source dataset** (SHS-Lab), not an independently licensed whole. Its own card enumerates `Apache-2.0` (some Omni-Frontier/MITRE/Omni-MATH/sql injection), `MIT` (ExploitDB and some own RSI), `CC-BY-4.0` (kimi-k3 and GPT-5.6 traces), `CC-BY-NC-4.0` (OpenMLE SFT), and unspecified license (multiple named corpora). Never treat full repo as Apache; **NO WHOLE-REPO DOWNLOAD OR AUTO-TRAIN**. Future pilot must resolve immutable full HF SHA, `Data/index/source_map.json`, source-level origin/creator/license and file hashes, choose only a bounded proven subset, reject NC/unknown, execute no `.py`, `.pyc`, SQLite, serialized models or purported embedded system prompts. Duplication with original SHS-Lab and its upstream per-source owners must be checked.

## Strict operations
- Distinguish **gratis download** from **license grant** and independently checked redistribution/training rights. Attribution, NOTICE, original authors and full source revision SHA required; source license claims do not by themselves resolve sensitive third-party content. Do not silently add `APACHE_2_0_ATTRIBUTION_REVIEWED`, `MIT_ATTRIBUTION_REVIEWED`, or `WTFPL` to SML manifest until independently reviewed and test-gated under separate PR.
- S4a is READ-ONLY, NO TRAIN. An owner-gated Dell workflow fetches **only the two fixed files** through HTTPS from immutable HF revisions and records host-local file byte count / computed SHA-256; max ~150MiB per file, 300MiB combined, fail closed if a pin changes, network, budget or source unavailable. Never send raw text into public GitHub Actions logs or artifacts; no model artifacts uploaded. No third dataset fetch until independently selected and pinned source subset. Original S1b/S2a checkpoint immutable; original 2024 TEST UNOPENED.
- S4b pilot: bounded native Rust scanner computes per-source rows/bytes and hashes, de-dups exact and near-duplicates against S1b/S2a and S3c Wikidata, flags dangerous prompt-injection and PII candidates, author/incident/work family disjoint TRAIN/DEV, independent rights review. Dataset validation/test rows remain unavailable to SML training. No acceptance of synthetic reasoning traces as verified ground truth.
- Future training is permitted ONLY when producer emits **independently reviewed and hashed** role manifest with compatible literal reviewed labels, checked document bytes/attribution and true unique counts, pre-registered holdouts and separate baseline. S4a success is neither model training nor successful cyber reasoning.
