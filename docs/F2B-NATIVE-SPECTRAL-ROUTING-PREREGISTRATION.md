# F2b-1 — Native TRAIN-calibrated spectral routing using the existing C12h engines

**Preregistered before implementation or measurement, 2026-10-20.** This is a bounded first F2b *engine integration* slice, not a completed whole F2b grid or an external independent test. F1 #631, F2 protocol #632, F2a gate #633 are merged. Keep A6-C12h's default CLI, matrix, prior results and seeds unchanged.

## Frozen grid and sources

Add an explicit opt-in --f2b mode to the existing `sml-noise-sample-phase-h-bench`. **Call its actual** W3 streaming proposer and W2+Sketch/MITM proposer and actual `fit_three_gate_candidates` with identical fit/validation streams. Do not duplicate or replace these engines. New conditions: n=128, task XOR3 or AND→XOR→XOR, independent Bernoulli label noise 0% or 40%, independent run identifiers 11 and 23 = 8 distinct deterministic trials. At noise 0 train proxy=128 64-bit words; at noise40 train proxy=512 64-bit words; train has 128-step causal halo. Initial network fit uses first TRAIN generator, internal validation uses second separate TRAIN generator. Both methods fitted using identical sources/candidates budgets where feasible; different proposal sizes are intrinsic to the frozen algorithms. Existing teacher functions define synthetic targets; the modeller receives no source truth.

Calibrate completed **committed** models on two independently generated TRAIN_cal documents of 640×64 target bits apiece, never updating fitted models. Use their real bit errors (not exact teacher source-match and not recovery-rate summaries) to supply the F2a gate. If a model cannot be fitted, treat its error as every calibration target wrong and never promote that arm. Pairing uses exact same calibration bytes and targets for both methods. Measure actual model search+fit wall clock, and each calibration eval time, charge **half the total search+fit cost into each calibration partition** plus its own eval time. This avoids a hidden free W3 training cost, although it only amortizes this small demonstration over the two calibration partitions and does not model production lifetime.

Gate fixed before results: minimum 1024 bits per partition, W3 gain >= 10000 ppm in **each** TRAIN_cal partition, both error rates <=500000 ppm, Hybrid total cost <=500000 ns per calibration target per partition and W3 <=1000000 ns per target. If neither route qualifies, Abstain, with no hidden fallback. Frozen once before generating DEV.

DEV generated after all fits/calibrations using a third independent stream: 4096×64 target positions per case. **Actually execute** selected method's autonomous committed network once for routed evaluation, or execute neither if Abstain. Separately evaluate BOTH models as shadow diagnostics on exact same DEV stream; shadow work excluded from routed time. Report method availability, TRAIN calibration errors, chosen route, DEV errors of each arm, chosen error, actual method calls, measured search+fit ns, calibration ns, DEV route time, independently generated stream identities and all wall-clock/parameter budget limitations.

## Evidence and STOP decisions

Per-run TSV schema `F2B_ROUTE_V1` fixed columns; same software source SHA for native Dell and Thor. Keep losses and error counts strictly in bits, not bits per octet. Require 8 distinct task/noise/seed rows per host, no invalid missing shapes, and artifacts with source SHA, machine architecture and sha256. **Do not enforce either method winning** as a CI requirement. Mark noise40 parity where both algorithms fail as valid scientific negative rather than a pass. This is a new synthetic stream grid built with historical teacher grammar, not an external-author corpus, not noise-LPN generally solved, and not future 25B model quality.

No SEC data (G0 NOT_ADMITTED), no frozen 2024 TEST, no GPU, no NVIDIA SDK. Later F2b-2 expands to n32/508, null/ambiguity and other noise levels and introduces independent generators. Neither code nor native runs may relabel old C12h held-out scores as TRAIN to leak prior TEST into the routing decision.
