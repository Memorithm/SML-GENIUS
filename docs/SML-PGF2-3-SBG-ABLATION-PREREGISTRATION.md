# PGF2-3 — K=2048 SBG representation ablation preregistration

Status: preregistered protocol. No result is recorded in this document.

This experiment is the PGF2-3 gate defined in `BOOTSTRAP.md`. It compares
the Pascal-GF(2) candidate against the mandatory reversible Boolean controls
before any MOR or Delta-KV handoff.

## Scope and non-claims

The logical state width is fixed at **K=2048 bits**.

These are controlled synthetic SBG geometry fixtures. They do not establish
natural-language understanding, model quality, novelty, training benefit,
latency benefit or production suitability.

No DKV protocol, MOR policy, context contract or model-core API is modified.

## Frozen transforms

Every input and every comparison signature is transformed by the same selected
arm before Hamming comparison.

1. **IDENTITY**
   - unchanged 2048-bit field.

2. **PERMUTE**
   - existing `semantic::rotate_permute`;
   - fixed shift = **683** logical coordinates.

3. **XOR_PERMUTE**
   - existing qualified SBG `semantic::bind` path;
   - one fixed role field shared by every record:
     `role_bit(i) = (31 + 73*i) mod 2048`, for `i = 0..63`;
   - therefore the arm is the current role-derived reversible permutation plus
     fixed XOR role mask, not a new mixer.

4. **PGF2**
   - merged `pascal_gf2_in_place` implementation;
   - 32 packed `u64` words;
   - 11 butterfly stages;
   - 11,264 logical XOR updates per transform;
   - 272 packed-word destination updates;
   - zero algorithmic scratch words beyond the output state.

All four arms must be deterministic and exact. PERMUTE and XOR_PERMUTE must be
reversed exactly by their existing inverse/unbind contracts. PGF2 must satisfy
`P(P(x)) == x`.

## Frozen fixture families

Two deterministic families are used so the experiment does not rely on only one
geometry regime.

### A. STRUCTURED_LOCAL

- classes: **32**;
- routes: **8**;
- class `c` is assigned route `c mod 8`;
- one common 2048-bit anchor is generated by the xorshift64 stream defined
  below and shared by every class;
- class `c` toggles exactly 16 coordinates
  `32*c + j`, `j = 0..15`;
- route `r` toggles exactly 32 coordinates
  `1024 + 64*r + j`, `j = 0..31`;
- a class prototype is common-anchor XOR class-mask;
- a route prototype is common-anchor XOR route-mask.

This panel deliberately contains local, low-complexity differences. Its purpose
is to test the hierarchical-mixing hypothesis directly.

### B. BALANCED_RANDOM

- classes: **32**;
- routes: **8**;
- one 2048-bit prototype is generated independently for each class and route
  from the same frozen xorshift64 generator with disjoint tags;
- all 32 packed words are emitted directly from the stream;
- no density correction, learned selection or post-hoc filtering is applied.

This panel is a negative/control regime: a globally invertible transform should
not be credited for information that was not present in the original state.

### Frozen generator

The generator is exactly:

```text
state = seed | 1
next:
    state ^= state << 13
    state ^= state >> 7
    state ^= state << 17
    return state
```

Base seed: `0x5047_4632_5342_4733`.

Tags are combined only with wrapping multiplication/XOR using these constants:

- class tag: `0x9e37_79b9_7f4a_7c15`;
- route tag: `0xd6e8_feb8_6659_fd93`;
- query tag: `0xc2b2_ae3d_27d4_eb4f`;
- noise tag: `0x1656_67b1_9e37_79f9`.

No random API, wall-clock seed or platform entropy is permitted.

## Frozen query/noise panels

For each class and route prototype, query variants are generated independently
of the transform arm.

### Uniform bit-flip panel

Per class, per seed `0..15`, flip exactly:

`h = {0, 1, 4, 16, 64}`

distinct coordinates sampled without replacement from all 2048 input
coordinates.

### Pair-boundary panel

For each class `c`, the deterministic confounder is `c XOR 1`.

Let `D(c)` be the sorted coordinates where the target and confounder prototypes
differ. For each direction `c -> c XOR 1`, flip the first:

- 1/4 of `|D(c)|`;
- 1/2 of `|D(c)|`;
- 3/4 of `|D(c)|`;

after rotating the sorted `D(c)` list by
`query_seed mod |D(c)|` for query seeds `0..15`.

This is a symmetric class-boundary stress, not a learned adversary. Exact
distance ties count as retrieval failure; no hidden tie-breaking credit is
allowed.

### Single-bit stability panel

For every input coordinate `0..2047`, compare the transformed zero vector
against the transformed vector with exactly that one input bit set.

Report output Hamming amplification:

- minimum;
- median;
- mean numerator/denominator;
- p95;
- maximum.

## Frozen measurements

For every transform arm and fixture family report:

1. **Exact collisions**
   - duplicate full 2048-bit transformed class prototypes;
   - duplicate full transformed route prototypes.

2. **Low-address collisions**
   - duplicate low 12-bit addresses among transformed class prototypes;
   - this matches the existing direct-routing low-address convention and is
     diagnostic only.

3. **Clean separation**
   - nearest wrong-class Hamming distance for every class;
   - nearest wrong-route Hamming distance for every route;
   - minimum, median and integer mean.

4. **Uniform-noise retrieval**
   - unique nearest-class retrieval accuracy for every `h`;
   - ties are failures.

5. **Uniform-noise routing**
   - unique nearest-route accuracy for every `h`;
   - ties are failures.

6. **Pair-boundary retrieval**
   - unique target retrieval accuracy at 1/4, 1/2 and 3/4 boundary movement;
   - ties are failures.

7. **Bit-flip stability**
   - complete 2048-coordinate amplification distribution.

8. **Structural cost**
   - state/output bytes;
   - algorithmic scratch bytes;
   - logical coordinate maps;
   - logical XOR updates;
   - packed-word updates where applicable.

No wall-clock latency is reported in PGF2-3.

## Frozen hypotheses and gate

Let **BEST_CONTROL** be the best of IDENTITY, PERMUTE and XOR_PERMUTE for the
specific metric. Because these controls are reversible isometries under full
Hamming distance, equality between them is expected for several metrics and is
itself valid evidence.

- **H1 — exactness**: all inverse/self-inverse checks pass and full-state
  collision counts do not exceed BEST_CONTROL.
- **H2 — structured separation**: on STRUCTURED_LOCAL, PGF2 improves the median
  nearest-wrong class distance by at least **10%** over BEST_CONTROL.
- **H3 — retrieval signal**: on at least one non-zero STRUCTURED_LOCAL uniform
  noise level or pair-boundary level, PGF2 improves unique class-retrieval
  accuracy by at least **20,000 ppm**, while degrading no other
  STRUCTURED_LOCAL retrieval cell by more than **10,000 ppm**.
- **H4 — routing signal**: on at least one non-zero STRUCTURED_LOCAL uniform
  noise level, PGF2 improves unique route accuracy by at least **20,000 ppm**,
  while degrading no other STRUCTURED_LOCAL routing cell by more than
  **10,000 ppm**.
- **H5 — random-control sanity**: BALANCED_RANDOM clean class separation and
  h=0 retrieval do not improve by more than **20,000 ppm** relative to
  BEST_CONTROL. A larger gain is treated as a fixture/implementation anomaly
  requiring investigation, not as evidence for PGF2.
- **H6 — local-noise bound**: PGF2 single-bit amplification p95 is at most
  **512 output bits** and maximum is at most **1024 output bits**.
- **H7 — cost bound**: PGF2 remains at the already qualified
  **11,264 logical XOR updates**, **272 packed-word updates**, **256 state
  bytes**, and **0 scratch words** per K=2048 transform.

### Selection

PGF2-3 may advance to a separately preregistered PGF2-4 MOR/Delta-KV handoff
only if:

- H1, H5, H6 and H7 hold; and
- H2 holds; and
- at least one of H3 or H4 holds.

Otherwise selection is **NONE** and PGF2 is retained as a negative or
component-only result. A failed selection must not be rescued by changing the
fixtures, thresholds or controls after execution.

## Reproducibility

The eventual executable must:

- be Rust-only;
- print deterministic integer/hex evidence;
- run twice in CI;
- require byte-identical stdout;
- retain the complete result artifact and execution manifest;
- keep model/context/MOR/DKV promotion blocked independently of test success.
